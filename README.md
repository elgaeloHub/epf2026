# Peering Capacity at Public Internet Exchanges: What the data reveals

This repository contains scripts and files used in the study presented at the European Peering Forum 2029 in Paris.

- `curl_all_ix.bash`: bash script that obtains all ix objects

- `curl_ixlan_by_asn.bash`: bash script that obtains all ixlan objects by asn

- `bash_curl_top10_cdn.bash`: bash script that uses the previous script for the top 10 ASNs

- `$ASN.csv`: files generated by the `curl_ixlan_by_asn.bash` script

- `all_ix.csv`: file generated by the `curl_all_ix.bash` script

- `all_data_combined.csv`: csv file that aggregates individual `$ASN.csv` files in the original `all_ix.csv`. It adds a column with the sum of the previous columns.
